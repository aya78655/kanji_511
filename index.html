問題用紙をつくる

パソコン：印刷画面で「PDFとして保存」（用紙A4・余白なし・倍率100%）。
iPhone：プリント画面の「共有」→「"ファイル"に保存」。Android：プリンタで「PDF形式で保存」。

GitHubに保存（パソコンとスマホで共有）

問題をGitHubのリポジトリに保存します。パソコンとスマホで同じ設定をすると、どちらで登録した問題も両方に出てきます。設定のしかた

  1. GitHubで、問題データ用の非公開（Private）リポジトリを作ります（例：kanji-data）。アプリを置いている公開リポジトリとは別にすると、問題が外から見えません。
  2. GitHubの Settings → Developer settings → Personal access tokens → Fine-grained tokens →「Generate new token」。
  3. Repository access で「Only select repositories」→ 1で作ったリポジトリだけを選びます。
  4. Permissions の Contents を「Read and write」にして作成し、表示されたトークン（github_pat_…）をコピーします。
  5. 下の欄に入力して「設定を保存して同期」を押します。スマホでも同じように入力します。
